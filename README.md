# Игра «Жизнь»

## Описание проекта

Игра «Жизнь» — это симуляция клеточного автомата, в которой пользователь может моделировать процесс жизни особей на клеточном поле. Каждая особь находится в отдельной клетке, а смена поколений происходит по определённым правилам.

### Правила игры:
1. В пустой клетке, рядом с которой ровно три живые клетки, зарождается жизнь.
2. Если у особи есть две или три живые соседки, она продолжает жить. В противном случае (если соседей меньше двух или больше трёх) особь умирает.

### Управление:
- **W, A, S, D** — перемещение по клеткам.
- **Управление мышкой** — изменение состояния выбранной клеткам.
- **Enter** — изменение состояния текущей клетки.
- **R** — запуск/пауза автоматической смены поколений.
- **Space** — смена одного поколения.
- **O** — смена одного поколения.
- **K** — очистка поля.
- **M** — открытие настроек.
- **Space** — Смена режима работы программы (Изменение конфигурации пользователем/режим работы игры).

### Основной функционал:
- Выбор стартовых клеток с особями.
- Смена поколений по правилам игры «Жизнь».

### Дополнительный функционал:
- Изменение настроек игры (размер поля, задержка между изменениями состояния поля).
- Изменение состояния клеток с помощью мыши.
- Возможность изменять состояние клетки в процессе работы программы.
